Product documentation

Privacy notice

Draft updated 23 October 2026. Public mainnet funding is open. This notice still requires review against the current hosting, waitlist and analytics configuration; legal review has not been represented as complete.

Wallet and blockchain data

Connecting a wallet reveals its public address to the page. Deal addresses, amounts, hashes, deadlines and transaction history are public on Arbitrum One. Do not place personal, confidential or secret information in on-chain fields or public delivery URLs.

Keys and signatures

AgentSolis does not request or store seed phrases or private keys. Wallet software displays and signs transactions. Never send a seed phrase or private key to AgentSolis support.

Product measurement

When product analytics is enabled, public AgentSolis pages record page views, selected navigation actions and approximate time on each page. Each browser tab receives a random session identifier stored only in session storage, so the dashboard reports approximate tab sessions rather than identified people. Events contain that identifier, the page path, page language, optional campaign label and time. A two-letter country code is recorded only when a trusted hosting edge removes user-supplied values or when the owner explicitly enables a GeoIP country resolver. When that resolver is enabled, the source IP is sent to that configured resolver only to obtain a two-letter country code; otherwise the country is shown as unknown. Bot and test traffic may be included. AgentSolis analytics do not store an IP address in the ordinary visitor table, advertising cookie, device fingerprint, email address or wallet address. Raw analytics events are retained for up to 760 days for year-over-year comparisons and are then deleted automatically. The hosting provider still processes ordinary request metadata such as IP address and browser information under its own operational logs.

Application logs

The hosting provider may process IP addresses, request times, browser information and error logs for security and reliability. AgentSolis keeps a separate, access-restricted security event log containing the source IP, event, requested path, country (when trusted) and time solely for abuse, fraud and security investigation. These raw IP records are automatically deleted after 180 days (approximately six months); they are not used to calculate visitor totals and are not linked to wallets or email identities unless a lawful, documented incident investigation requires it. The application should not log full delivery content, wallet signatures or confidential evidence.

Founding 50 applications

A Founding 50 application stores the public participant-wallet address, the selected role (buyer, seller or both), the short use-case description supplied by the applicant, the application time and its review status. The signed challenge is verified to prove wallet control and is not retained as part of the application. Do not include personal or confidential information in the use-case description.

AI dispute review

If a Buyer Review dispute is opened, the agreed terms, delivery, claim and evidence manifest may be stored in the private review database and sent to three configured AI providers. Do not include secrets or personal data that are not necessary to decide the dispute. Provider names, retention periods, deletion process and international-transfer details must be published before this feature accepts public cases.

External services

Wallets, RPC providers, Arbiscan, content hosts, AI review providers and linked services operate under their own privacy terms. Opening an external link or starting an AI review sends a request to that provider.
